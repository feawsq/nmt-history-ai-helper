# 🇺🇦 НМТ Історія України: ШІ-Тренажер (Privacy First)

Веб-застосунок для випускників 11 класів для підготовки до Національного мультипредметного тесту (НМТ) з історії України з персональним ШІ-тьютором «Кліо» (Gemini 3.8 Flash), симулятором іспиту на 30 завдань і повною конфіденційністю (нульовий збір персональних даних).

---

## 🚀 Як запустити застосунок на своєму комп'ютері

### Варіант 1. Запуск через браузер прямо зараз (без встановлення)
Ви можете користуватися застосунком онлайн без будь-яких команд та встановлення програм:
👉 **[Відкрити веб-версію тренажера](https://ais-dev-26edvp2q4eozpk5x3onxm4-3994717271.europe-west1.run.app)**

---

### Варіант 2. Локальний запуск на комп'ютері (Windows / Mac / Linux)

#### 1. Встановіть Node.js
Переконайтеся, що на комп'ютері встановлено **Node.js** (версія 18 або новіша):
- Завантажте з офіційного сайту: [https://nodejs.org](https://nodejs.org) (рекомендовано версію LTS).

#### 2. Завантажте файли проєкту
Завантажте папку з цим проєктом або клонуйте репозиторій:
```bash
git clone <посилання-на-репозиторій>
cd <назва-папки>
```

#### 3. Налаштуйте ключ Gemini API
Створіть файл `.env` у кореневій папці проєкту (скопіювавши з `.env.example`):
```bash
cp .env.example .env
```
Відкрийте файл `.env` та вкажіть ваш ключ Google Gemini API:
```env
GEMINI_API_KEY="ваш_ключ_gemini"
```
*(Отримати безкоштовний ключ можна на [Google AI Studio](https://aistudio.google.com/app/apikey))*

#### 4. Встановіть залежності
У терміналі (Командний рядок, PowerShell або Terminal на Mac) виконайте:
```bash
npm install
```

#### 5. Запустіть застосунок
Виконайте команду запуску сервера розробки:
```bash
npm run dev
```

#### 6. Відкрийте в браузері
Перейдіть у браузері за адресою:
👉 **`http://localhost:3000`**

---

## 🛠️ Команди
- `npm run dev` — запуск локального сервера розробки з бекендом Express та Vite на порті 3000.
- `npm run build` — оптимізована збірка клієнтської частини для продакшну.
- `npm run lint` — перевірка типів TypeScript.

---

## 🛡️ Конфіденційність (Privacy First)
- **Zero Server Storage:** Сервер не має бази даних і не зберігає жодних записів про учнів.
- **Client Storage:** Усі бали, спроби, картки та нотатки записуються виключно у ваш браузер (`localStorage`).
- **Експорт/Імпорт:** У будь-який момент можна скачати свій прогрес у JSON або очистити дані без сліду.
